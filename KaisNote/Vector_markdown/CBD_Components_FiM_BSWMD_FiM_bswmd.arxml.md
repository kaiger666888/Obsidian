# FiM

## 模块描述

Function Inhibition Manager (FiM)
Allows querying the permission / inhibition status of software components and the functionality
therein. An application functionality can be identified along with its inhibition conditions.
#Diag #Diagnostics #OBD #WWHOBD
#AUTOSAR #ServiceComponent

## 容器列表

### 1. FiMConfigSet

**描述**: This container contains the configuration parameters and sub containers of the FiM module supporting
multiple configuration sets.

该容器没有参数。

### 2. FiMFID

**描述**: This container includes symbolic names of all FIDs.

#### 参数列表

```yaml
- 
  序号: 1
  名称: FiMFunctionId
  长名称: ''
  描述: Unique identifier of a FimFunctionId. This parameter should not be changeable by user, because
      the Id should be generated by Fim itself to prevent gaps and multiple use of an Id.
  默认值: 0
  最小值: 0
  最大值: 65535
```

### 3. FiMInhibitionConfiguration

**描述**: This container includes all configuration parameters concerning the relationship between event and
FID.

#### 参数列表

```yaml
  序号: 1
  名称: FiMInhInhibitionMask
  长名称: ''
  描述: This parameter defines the inhibition mask for a DEM event - FID relation.
  默认值: FIM_TESTED
  最小值: ''
  最大值: ''
```
