### 2. DltMemory

**描述**: Configuration parameters for reserving memory for some internal storing and buffer.

#### 参数列表

```yaml
- 
  序号: 1
  名称: DltInitBufferSize
  长名称: ''
  描述: Buffer size for the C-init buffer. This buffer is for storing messages from other BSW modules
      before Dlt is initialized.
  默认值: ''
  最小值: 0
  最大值: 4294967295
- 
  序号: 2
  名称: DltMaxCountAppIds
  长名称: ''
  描述: The maximum count of register able Application Ids. There shall be a table to manage
      registered Application IDs, this is the number of lines to hold in this table.
  默认值: ''
  最小值: 1
  最大值: 4294967295
- 
  序号: 3
  名称: DltMaxCountContextIds
  长名称: ''
  描述: The maximum count of registrable Context Ids. There shall be a table to manage registered
      Context IDs, this is the number of lines to hold in this table.
  默认值: ''
  最小值: 1
  最大值: 4294967295
- 
  序号: 4
  名称: DltMaxCountContextIdsPerAppId
  长名称: ''
  描述: Each Context ID belongs to a specific Application ID. Dlt shall handle the correlation between
      them. The table of the registered Application IDs shall hold for every Application ID
      several references to the proper Context IDs. This is the maximum count for Context IDs
      per Application ID.
  默认值: ''
  最小值: 1
  最大值: 4294967295
- 
  序号: 5
  名称: DltMessageBufferSize
  长名称: ''
  描述: Buffer size for storing Dlt messages for waiting to transmit over the Network (send buffer).
  默认值: ''
  最小值: 0
  最大值: 4294967295
```

DltImplementNVRamStorage is not set, Link-Time or Post-Build configuration shall be uesd.

```yaml
- 
  序号: 1
  名称: DltBandwidthForComModule
  长名称: ''
  描述: For communication over the Dlt Communication Module the maximum bandwidth shall be set.
  默认值: ''
  最小值: 0
  最大值: 4294967295
- 
  序号: 2
  名称: DltBandwidthForDiagChannel
  长名称: ''
  描述: For communication over the DCM and as follows over the diagnostic interface the maximum
      bandwidth shall be set.
  默认值: ''
  最小值: 0
  最大值: 4294967295
- 
  序号: 3
  名称: DltTimePeriodTrafficShaping
  长名称: ''
  描述: For implementing a traffic shaping, a time window for measuring shall be provided.
  默认值: ''
  最小值: 0
  最大值: Inf
```

### 5. DltMessageFiltering

**描述**: Configuration parameters for setting message filtering properties in Dlt module.

#### 参数列表

```yaml
- 
  序号: 1
  名称: DltDefaultMaxLogLevel
  长名称: ''
  描述: The maximum log level a received message (from SW-C to Dlt) can have. This can also be
      modified at runtime and stored persistently in NVRAM. If DltImplementNVRamStorage is
      enabled this parameter is the initial value for the corospending NVRam entry. If
      DltImplementNVRamStorage is not set, Link-Time or Post-Build configuration shall be
      uesd. The value 0 means loging is disabled.
  默认值: ''
  最小值: 0
  最大值: 6
- 
  序号: 2
  名称: DltDefaultTraceStatus
  长名称: ''
  描述: Tells if trace messages shall be forwarded by Dlt. This functionality can also be modified at
      runtime and changed can stored persistently in NVRAM. If DltImplementNVRamStorage is
      enabled this parameter is the initial value for the corresponding NVRam entry. If
      DltImplementNVRamStorage is not set, Link-Time or Post-Build configuration shall be
      used.
  默认值: ''
  最小值: ''
  最大值: ''
- 
  序号: 3
  名称: DltFactoryDefaultMaxLogLevel
  长名称: ''
  描述: The maximum log level a received message (from SW-C to Dlt) can have. This is for setting
      DltDefaultMaxLogLevel to factory defaults. The value 0 means loging is disabled.
  默认值: ''
  最小值: 0
  最大值: 6
- 
  序号: 4
  名称: DltFilterMessages
  长名称: ''
  描述: This flag gives the Dlt the instruction to filter or not to filter incoming log or trace
      messages. If it is not set all incoming messages are forwarded to the communication
      channel. So also the caller of the DltSendXXXMessage can leave the field trace_info or
      log_info empty.
  默认值: ''
  最小值: ''
  最大值: ''
```

```yaml
  描述: This is the name of the ECU for use within the Dlt protocol. The meaning is described in the

  默认值: ''
  最小值: ''
  最大值: ''
- 
  序号: 2
  名称: DltHeaderPayloadEndianes
  长名称: ''
  描述: Determines the endianes of the CPU (Most Significant Byte).

  最大值: ''
- 
  序号: 3
  名称: DltHeaderUseEcuId
  长名称: ''
  描述: Corresponds to field WEID (With ECU ID). If set ECU ID shall be placed in the header, else
      not.
  默认值: ''
  最小值: ''
  最大值: ''
- 
  序号: 4
  名称: DltHeaderUseExtendedHeader
  长名称: ''

  最小值: ''
  最大值: ''
- 
  序号: 5
  名称: DltHeaderUseSessionID
  长名称: ''
  描述: Corresponds to field WSID (with Session ID). If set the Session ID shall be placed in the
      header, else not.
  默认值: ''
  最小值: ''
  最大值: ''
- 
  序号: 6
  名称: DltHeaderUseTimestamp
  长名称: ''
  描述: Corresponds to field WTMS (With Timestamp). If set the timestamp shall be placed in the
      header, else not.
  默认值: ''
  最小值: ''
  最大值: ''
- 
  序号: 7
  名称: DltMaxMessageLength
  长名称: ''
  描述: The maximum length of a Dlt log or trace message.
  默认值: ''
  最小值: 8
  最大值: 65535
- 
  序号: 8
  名称: DltUseVerboseMode
  长名称: ''
  描述: If this flag is set Dlt shall use the Verbose Mode for generating the header of the transport

      Verbose Mode shall be used.
  默认值: ''
  最小值: ''
  最大值: ''
```
