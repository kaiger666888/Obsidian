# Xcp

## 模块描述

Universal Calibration Protocol. XCP is a protocol description based on the ASAM standard between a
master (tool) and a slave (device), which provides possibility to calibrate and measure data on the
slave.
#Xcp #CANape #CAN #Ethernet #FR #ASAM #AUTOSAR

### 17. XcpCRC

**描述**: The XCP command BUILD_CHECKSUM returns a checksum that is calculated over the memory block defined
by the Memory Transfer Address (MTA) and block size. The MTA will be post-incremented by the block
size.

If enabled, the checksum type (size of the checksum) and the calculation method must be configured.

```yaml

  长名称: ''
  描述: |
```
