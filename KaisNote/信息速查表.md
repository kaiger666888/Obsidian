## Dynamic versioning


	动态生成版本号:
```bash
poetry self add "poetry-dynamic-versioning[plugin]"
```

	该插件允许项目的版本号（`version`）在构建时​**​动态生成​**​（而非硬编码在 `pyproject.toml` 中），例如：
	
	- 基于 Git 标签（如 `git describe`）自动生成语义化版本（SemVer）。
	- 根据提交哈希或日期生成开发版本（如 `0.1.0.dev1+abcdef12`）。

## Make editable package
### 链接主项目和Dependencies
#### 方法1：
```bash
poetry run python -m pip install -e "<DependencyPath>"
```
*Note: 
	1. Do this in yaml2arxml's terminal
	2. Location to editable package is relative repo root
	3. Has to be added after each install*
path link file would then be created:
![[Pasted image 20250516140005.png]]
*Note： 
1. 操作最简单
2. 不会更改project.toml和poetry.lock
3. 适合主项目和Dependency联调时使用*
#### 方法2：
##### 在依赖包目录:
```bash
poetry build
```

##### 在主项目目录:
```bash
poetry add <DependencyPath>
```
*Note： 
1. 与下面方法3产生同样效果但是操作简单
2. 会更改project.toml和poetry.lock
3. 适合在需要在主包构建Conan package时使用*
#### 方法3：
Add editable dependency info in toml 
```toml
vcc-autosar = { path = "../../Git_autosar_library/autosar_library_master_20250409_portForElement", develop = true }
```
in
```toml
[tool.poetry.dependencies]
```
then do
```
poetry lock
```

# pyenv相关
## Python版本管理
### 查看所有可用版本（包括旧版）
```bash
pyenv install --list
```
### 安装 Python 3.11.4
```bash
pyenv install 3.11.4
```
### 卸载某个版本
```bash
pyenv uninstall 3.9.13
```
## 设置使用版本

### 设置全局默认版本（写入 ~/.pyenv/version）
pyenv global 3.10.5

### 为当前目录设置局部版本（写入 .python-version）
pyenv local 3.11.0

### 临时设置当前 shell 会话的 Python 版本
pyenv shell 3.9.13
